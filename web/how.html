KK Map Find a route

From corridors to the shortest walk

K Map turns Block A & B into a graph and uses Dijkstra's algorithm, written in C++, to find the walk with the fewest steps between any two places.

The building as a graph

A graph is a set of places (nodes) joined by links (edges). Each link has a weight: here, the number of walking steps along it.

  • Places: every room, the spot in the corridor outside each door, every corner where corridors meet, the staircases, toilets and entrances.
  • Links: the piece of corridor between two places next to each other. You can walk a corridor both ways, so every link works in both directions.
  • Floors: all four floors have the same layout. Each staircase links a floor to the one above it, about 25 steps per floor.

The C++ keeps the graph as an adjacency matrix: a table with one row and one column per place, where matrix[u][v] is the number of steps between u and v, or -1 if no corridor joins them. Every corridor works both ways, so the table is symmetric.

Dijkstra's algorithm, in four steps

Each place gets a number: the fewest steps found so far from the start. The start is 0, everything else begins as "not reached" (∞). Then repeat:

  1. Pick the closest place that isn't finished yet.
  2. Finish it. Nothing can reach it more cheaply now, because every other unfinished place is already at least as far away.
  3. Relax its neighbours: if walking through it gives a neighbour a shorter total, write down the new total and remember where it came from.
  4. When the destination is finished, follow the "came from" notes backwards to read off the route.

This is the simple version: step 1 looks through every place, and step 3 looks along the place's whole row of the matrix, so each round costs up to V checks and the whole search is O(V²) for V places. With 412 places that's about 170,000 checks, which takes well under a millisecond.

Nearest toilet, stairs or way out

There is no new algorithm here. K Map runs the same Dijkstra from your room to every candidate, for example each Gents toilet on every floor, and keeps the one with the fewest steps.

Where the numbers come from

Our team walked every corridor counting steps, writing down a running count at each door. The difference between two counts is the weight of the link between them. 42 of the 62 corridor pieces were counted this way; the rest were worked out from those counts. Staircases are about 25 steps per floor, and times assume about 100 steps a minute.

Where it runs

The Dijkstra code is C++ (cpp/graph.cpp). It is compiled to WebAssembly, so the same C++ runs inside your browser: no server is involved in finding a route.
